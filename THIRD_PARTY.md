# Third-party components

`open-rknpu` is MIT licensed (see [LICENSE](LICENSE)). This file lists every third-party
component the repository **ships**, **fetches** or **references**, with its licence and how
it is obtained. Nothing in this list is a vendor SDK: no Rockchip binary, no RKNN library
and no GPL kernel source is redistributed here.

## Shipped in the repository

| Component | Where | Licence | Notes |
| --- | --- | --- | --- |
| ONNX (runtime dependency) | `pyproject.toml` | Apache-2.0 | used to load and normalise graphs; never linked into the board runtime |
| NumPy (runtime dependency) | `pyproject.toml` | BSD-3-Clause | host arithmetic and the integer references |
| pretrained MNIST model | `research/pretrained/mnist/` (`normalized.onnx`, upstream `mnist-12.onnx`, source/model licence files) | Apache-2.0 (model), MIT (example code) | the classifier example's NPU prefix; provenance in `research/pretrained/mnist/source.json` |
| pretrained Fashion-MNIST model | `research/pretrained/fashion-mnist/` | MIT (Zalando Research), MIT (example code) | trained by `examples/fashion/train.py` from the dataset |
| `rocket_registers.h` | `research/hardware_refs/` | **GPL-2.0-only OR MIT** | dual-licensed; this project uses it under the **MIT** option, with the upstream copyright header retained |
| board evidence | `research/*/model*.bin`, `input*.u8`, `expected*.i8`, `board_results_*.json` | MIT | generated by this project on the attached board |
| vendor-toolkit fixtures | `research/fixtures/*/model.rknn`, decoded captures (`*.1`, `*.bfd`, `*.replay`) | MIT (our models/captures) | generated from **our own** ONNX graphs with the vendor toolkit used strictly as a development oracle; see [docs/provenance.md](docs/provenance.md) |

## Fetched by the user (never redistributed)

| Component | Fetched by | Licence | Notes |
| --- | --- | --- | --- |
| Rockchip/Luckfox cross toolchain | `research/fetch_toolchain.py` | vendor toolchain licence (Rockchip/Luckfox SDK) | needed only to build the board runtime; the repository ships the C sources instead |
| Luckfox kernel driver sources | referenced by filename only — see [research/vendor/README.md](research/vendor/README.md) | **GPL-2.0** | read as documentation during reverse engineering; removed from this repository, provenance (upstream URL, commit, per-file sha256) retained |
| MNIST IDX files | `examples/fetch_idx.py --dataset mnist` | Yann LeCun's MNIST page terms (research use) | sha256-pinned download |
| Fashion-MNIST IDX files | `examples/fetch_idx.py --dataset fashion` | MIT (Zalando Research) | sha256-pinned download |
| Free Spoken Digit Dataset (FSDD) | `examples/mel-kws/fetch_data.py` | **CC BY-SA 4.0** | sha256-pinned archive; not redistributed. The `examples/mel-kws/` weights are trained on it — see the licence note in that example's README |
| RK3588 TRM and other Rockchip documents | not included | vendor document licence | used as related-hardware references during development and deliberately excluded |
