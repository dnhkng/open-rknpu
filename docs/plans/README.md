# Planning records

These are the project's working documents in the form they were used: they record what was
planned, what the plan got wrong, and how each item was closed. They are kept because the
*reasoning* is evidence too — several conservative bounds in the compiler exist because a
plan item was measured and failed.

| Document | What it records |
| --- | --- |
| [project-goals.md](project-goals.md) | the original project goals and the ordered triage over the primitive matrix |
| [coverage-matrix.md](coverage-matrix.md) | the ten-category Conv/Mul coverage matrix that defined the work queue |
| [primitive-roadmap.md](primitive-roadmap.md) | the historical milestone checklist, and the measured envelope against a real pretrained model (Silero VAD) |
| [completion-plan.md](completion-plan.md) | the phasing (P1–P9) of the remaining work and the final disposition of every residual |
| [pipelining-plan.md](pipelining-plan.md) | the S1–S10 submission/pipelining investigation, including the superseded conclusions |
| [cleanup-plan.md](cleanup-plan.md) | the C1–C5 codebase cleanup and its no-container-change verification |
| [milestone-record.md](milestone-record.md) | the original project README, kept verbatim as the chronological narrative |

Current documentation starts at [../README.md](../README.md); the day-by-day register-level
record is [../investigation-log.md](../investigation-log.md).
